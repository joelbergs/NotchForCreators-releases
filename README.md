# Notch For Creators — downloads

This repository serves the downloadable builds of
[Notch For Creators](https://notchforcreators.com), a macOS menu-bar app for
people who work at the top of the screen. The source is developed in a
private repository; the builds land here so the website can hand out
downloads from a domain browsers already trust.

Every build is a universal binary — Apple silicon and Intel — signed with an
Apple Developer ID and notarised by Apple. Take the current version from the
[Releases page](../../releases/latest) or from
[notchforcreators.com](https://notchforcreators.com/#download).
